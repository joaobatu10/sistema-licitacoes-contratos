⚠️ Atenção: Problema de Tokens Detectado

O sistema detectou tokens antigos que estão causando erros na funcionalidade de deletar processos.

Isso acontece porque os tokens foram atualizados para um formato mais seguro.

O que precisa ser feito:

  1. Limpar tokens antigos (clique no botão abaixo)
  2. Fazer login novamente para obter um token no formato correto
  3. Testar a funcionalidade de delete

📋 Detalhes Técnicos:

  • Problema: Tokens antigos usam formato de username (string)
  • Solução: Novos tokens usam formato de user_id (integer)
  • Impacto: Delete operations retornavam erro 500
  • Status: Backend corrigido e rodando

Após limpar os tokens:

1. Você será redirecionado automaticamente para o login se tentar acessar páginas protegidas

2. Faça login normalmente com suas credenciais

3. A funcionalidade de delete funcionará corretamente
